## WorkerW Desktop Integration Technique

The technique of embedding windows behind desktop icons using the WorkerW
window layer is a well-documented approach used by multiple open-source
desktop wallpaper applications. This technique was studied from publicly
available documentation and open-source implementations.

## AutoWall

Intonaco's desktop integration approach was informed by studying the
AutoWall project (https://github.com/SegoCode/AutoWall), which is
licensed under the GNU General Public License v3.0.

The AutoWall project demonstrates the WorkerW desktop integration
technique for live wallpaper applications on Windows.
